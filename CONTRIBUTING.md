# Contributing

Thanks for helping! Good first contributions:

- Add or fix app shortcuts (package names differ between TV brands) in `APPS` inside `MainActivity.kt`.
- Report which TV brands/models work, using the "TV compatibility" issue template or a plain issue.
- UI polish, an app icon, light theme, a touchpad/gesture mode, multiple saved TVs.

## Workflow
1. Fork the repo and create a branch.
2. Make your change. The CI build (`Build APK`) must pass.
3. Open a pull request describing what changed and which TV you tested on.

Please keep the app free of ads, trackers and analytics.
